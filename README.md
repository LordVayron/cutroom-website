# Cutroom landing page

Live: https://cutroom-website-delta.vercel.app

Responsive, buildless product website. The editing app is separate:
https://github.com/LordVayron/cutroom

Serve `dist/` with a static server. Vercel uses the tracked configuration and
publishes `dist/`. No credentials, server runtime, or package install are needed.

The hero is AI-generated illustrative artwork not a
customer or endorsement. Product images capture the actual Cutroom frontend
with synthetic demo data. No private episodes, transcripts, or personal paths
belong in this repository. All product download buttons target the public app repo.

The site uses Google Fonts (an external font request); it has no analytics,
cookies, account forms, or tracking scripts. Font fallbacks work offline.

Visual revision: clearer problem/workflow/feature sections, 2× lossless application
captures, deliberate workspace perspective, reduced-motion-aware scroll entrances,
a solid plum footer wordmark, and fictional background clip imagery. See ASSETS.md
for asset provenance. No private episodes are used.

Studio graphics revision: detailed HTML/CSS editing scenes replace sparse cards
and icons. Only the brand screenshot is tilted; workspace and Director Mode remain
level. Decorative scenes reuse fictional hero imagery, not private media. They
illustrate concepts rather than claim to be screenshots of additional app features.

Entrance animations now cover meaningful content groups across the entire page,
including hero, problem, workflow, features, CTA, FAQ, and footer. Content remains
visible without JavaScript or with reduced motion, including preference changes.
The footer uses the original two-tone PNG without the former solid alpha mask.

GitHub actions use a shared branded treatment: GitHub mark, sage/plum surfaces,
separate arrow detail, keyboard focus, and reduced-motion-aware hover effects.
Repository destinations remain unchanged.

Editorial revision (2026-10-22): stronger product-definition and feature-section
hierarchy, with a branded closing install-prompt handoff. The copy button copies
the public repository URL and safe local setup instructions, never credentials.
Clipboard denial opens a selectable prompt; without JavaScript the same prompt
remains available through native details/textarea controls. Desktop, tablet,
mobile, clipboard success/denial, and no-JavaScript behavior were checked.
