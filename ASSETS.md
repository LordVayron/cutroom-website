## Actual application captures

`workspace.webp`, `director.webp`, and `brand.webp` are captured at 3200 × 2000
pixels (2× device scale), losslessly encoded. They show the actual frontend with
synthetic fixture data, never private projects or transcripts. Workspace and
Director Mode remain level; only the brand screenshot has a CSS tilt.

The studio illustrations are code-native HTML/CSS using existing fictional
imagery: an editing timeline, source/ranking/caption scenes, crop guides, audio
waves, and a weekly plan. No additional image generation was needed for this pass.

The footer renders the existing PNG wordmark as a solid plum CSS mask, avoiding
the old darkened, low-contrast filter. No new logo was generated.
