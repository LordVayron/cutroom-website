# Website visuals

## Hero depth revision

Asset: `dist/assets/hero-depth.webp`. Created with the built-in image-generation
tool, then encoded as WebP. The previous hero remains available for rollback.
All additional guests/scenes are fictional illustration, not endorsements.

## Actual application captures

`workspace.webp`, `director.webp`, and `brand.webp` are captured at 3200 × 2000
pixels (2× device scale), losslessly encoded. They show the actual frontend with
synthetic fixture data, never private projects or transcripts. CSS supplies the
deliberate workspace perspective rather than baking a tilt into a low-res image.

The footer renders the existing PNG wordmark as a solid plum CSS mask, avoiding
the old darkened, low-contrast filter. No new logo was generated.
